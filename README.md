# 坦克大战 Tank Battle

一个用原生 HTML5 Canvas 编写的单文件「坦克大战」小游戏,经典街机风格,**零外部依赖**,双击 `index.html` 即可在浏览器中直接游玩。

## 玩法

控制你的坦克消灭敌军,同时**守住地图下方的基地**。

- 基地被击中,或生命耗尽 → 游戏结束
- 清空本关全部敌军 → 进入下一关(共 3 关)

地图元素:

| 符号 | 含义 | 说明 |
| --- | --- | --- |
| `#` | 砖墙 | 可被子弹击碎 |
| `@` | 钢墙 | 无法击碎,子弹会被弹开 |
| `~` | 水面 | 坦克不能通过,子弹可穿过 |
| `%` | 草丛 | 坦克可进入并隐藏 |
| `B` | 基地 | 被击中即失败 |

## 操作

| 动作 | 按键 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 射击 | 空格 / J |
| 暂停 | P / Esc |
| 开始 / 重新开始 | Enter |

移动端自动显示屏幕方向键与射击按钮。

## 运行

方式一:直接用浏览器打开 `index.html`。

方式二:用任意静态服务器托管:

```bash
python -m http.server 8080
```

## 在线游玩

在仓库的 **Settings → Pages** 中将 Source 设为 `main` 分支,即可通过
`https://<用户名>.github.io/tank-battle/` 在线游玩。
